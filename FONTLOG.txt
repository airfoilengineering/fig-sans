FONTLOG for Fig Sans
--------------------

This file gives detailed information about the Fig Sans font software.
Distribute it with the Fig Sans fonts and with any work derived from them.


Basic Font Information
----------------------

Fig Sans is the logotype typeface for Fig. It is a modified version of
Uncut Sans, designed by Kasper Nordkvist for UNCUT.wtf.

Fig Sans is a single static style, Fig Sans 450 Regular. It was taken from
the Uncut Sans variable font, version 1.304, at weight 450, with the
italic axis at 0. Some letters were then redrawn and respaced to suit the
Fig logotype and its sub-brand logos.

Metarch Corporation (Fig) holds the copyright in the Fig Sans
modifications. Like the rest of the font, they are released under the
SIL Open Font License, Version 1.1, which nobody may restrict. See OFL.txt. "Uncut Sans" is a trademark of Kasper Nordkvist. Fig Sans is not
made, endorsed or supported by Kasper Nordkvist or UNCUT.wtf.

ChangeLog
---------

15 November 2026 (Airfoil) Fig Sans Version 1.002
- The copyright notice now names Fig's legal company, Metarch
  Corporation. No glyphs, spacing or features changed.

15 November 2026 (Airfoil) Fig Sans Version 1.001
- Updated the credits and details stored inside the font files. No
  glyphs, spacing or features changed.
- The copyright notice keeps Kasper Nordkvist's original notice and
  names Fig as owner of the modifications. Version 1.000 only said
  "Modified 2026 by Rikki Janae (i and l glyphs)".
- Manufacturer is now Airfoil instead of UNCUT.wtf. Designer now names
  both Kasper Nordkvist and Rikki Janae.
- Added a description listing the changed letters, and a link to
  https://github.com/airfoilengineering/fig-sans
- Set the version to 1.001 everywhere. Version 1.000 still carried the
  Uncut Sans revision number, 1.304, in its header.
- The family name stays "Fig Sans 450", so existing design files keep
  working.

14 November 2026 (Airfoil) Fig Sans Version 1.000
- First release, based on Uncut Sans 1.304.
- Made a static instance at weight 450.
- Changed the outlines and spacing of these lowercase letters:
  a b c d e g i l n o p r
  Accented letters built from them change with them.
- Added an fi ligature (U+FB01).
- Renamed the family to Fig Sans 450. The font does not use the name
  "Uncut Sans".
